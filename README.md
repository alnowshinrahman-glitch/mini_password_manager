# Mini Password Manager

A simple command-line password manager built with Python and JSON, inspired by how browser password managers (like Google Password Manager) store and retrieve credentials.


---

## 🚀 Features

- Add credentials (website, username, password)
- View saved credentials by website
- Persistent storage using a JSON file
- Menu-driven command-line interface
- Modular and readable code structure

---

## 🛠️ Technologies Used

- Python 3
- JSON: for persistent data storage
- Git & GitHub: version control

---

## How It Works 

- Passwords are stored in a dictionary structure in memory
- Data is loaded from data.json when the program starts
- Any updates are saved back to data.json
- Users interact with the program through a menu system

##Example data format in data.json:
{
  "github.com": {
    "username": "exampleUser",
    "password": "examplePassword"
  }
}
